# Exploratory layouts and presentation

The [presentation directory](presentation/README.md) contains the current photonic-NPU pitch, budget, and technical assumptions.

The microcomb.py and photonic_retina.py files and associated GDS files are earlier generic-PDK layout experiments. A resonator geometry or array alone does not establish soliton generation, sensing, a numerical processor, or foundry qualification. The current NPU compute core is still a proposed design.

These experiments retain their existing paths and imports. They require additional layout dependencies beyond the root simulation requirements. Historical pitch files and reviews have moved into [presentation/archive](presentation/archive/README.md).
